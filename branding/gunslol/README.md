## Customize

| Setting | Value |
|---|---|
| Accent colour | `#f2c14e` (gold) |
| Text colour | `#f4f0ff` |
| Background colour / overlay | `#07060f` |
| Icon colour | `#b49bff` (violet) |
| Profile opacity | 60–70 % · **Blur** 10–15 px |
| Username effect | glow (gold) · **Cursor** a small gold dot or the default |
| Background effect | none or "night" (the image already has stars) |
| Audio | optional: an ambient / synthwave loop, volume low, "click to enter" on |
| Badges | show them; the profile views counter on |

## Spec (why it looks like this)

1. **One identity everywhere**: same palette, same V and same motto as the GitHub profile and
   The Seed (design tokens V2: night violet `#07060f`, violet `#8f6cf0`, gold `#f2c14e`).
2. **Five seconds**: who V is (42, full-stack, AI, blockchain), what he builds (The Seed), and
   a teaser (The Seed OS).
3. **Nothing private**: no private repository, no security detail, no wallet address.
4. **Upkeep**: when The Seed reaches a step of its roadmap, update the second typewriter line.
